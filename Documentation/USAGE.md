# 使用手册

本文档介绍 BloodPressureCam 的界面结构与主要功能操作流程。

## 导航结构
应用采用底部 `TabView`，包含以下模块：

1. **记录**：浏览、搜索与管理历史测量数据。
2. **统计**：查看近 7 / 30 / 90 天及 1 年的趋势图与关键指标。
3. **拍照**：调用相机对准血压计屏幕拍照，并进入手动校准页面。
4. **报告**：生成带有图表与明细表格的报告，可导出 PDF。
5. **设置**：配置提醒、高压高亮等偏好。

## 首次使用
- 启动应用后，记录页用于展示数据；若为空，会提示通过右上角 **+** 或 “拍照” 标签新增。
- 授权相机与照片写入权限，确保能够保存拍摄的设备读数。

## 新增测量
### 方式一：直接进入“拍照”标签
1. 点击底部相机图标进入拍照流程。
2. 允许相机权限后，将血压计屏幕置于取景框内点击快门。
3. 完成拍照后自动打开“手动录入”表单，照片已预填。
4. 校准或补充高压、低压、心率、体感、姿势、体重、备注等信息。
5. 点击“保存”即可写入记录并回到列表。

### 方式二：记录页右上角 “+”
1. 在记录页点击 “+”。
2. 在表单页手动或通过“拍照/相册”按钮附带照片。
3. 填写数据并保存。

> **提示**：系统默认高压 >= 低压，若输入错误会提示校正。

## 浏览与编辑记录
- 记录页使用分段控件筛选不同测量类别（血压/血糖）。
- 点击任意条目进入详情，可回看照片、查看全部字段并支持“编辑”或删除。
- 左滑条目并选择“Delete”可快速删除。

## 统计页
- 顶部分段控件切换时间范围。
- 折线图展示高压、低压的趋势；下方卡片显示平均值、最高/最低等。
- 根据波动情况给出趋势建议文案。

## 报告页
1. 同样可切换时间范围。
2. 预览包含标题、日期区间、趋势图、统计摘要和明细表格。
3. 右上角分享按钮生成 PDF 并唤起系统分享，可保存到“文件”或发送给医生。

## 设置页
- **高血压提醒高亮**：记录列表在高血压等级时强化颜色提醒。
- **测量提醒**：开启后可设置常规测量时间（仅保存偏好，提醒逻辑可接入 `UserNotifications` 扩展）。
- **关于**：展示版本号并提供隐私政策、反馈邮件链接。

## 数据存储
- 所有测量以 JSON 形式存储在沙盒 `Documents/blood-pressure-readings.json`。
- 照片保存于 `Documents/ReadingPhotos/` 目录，文件名与记录 UUID 对应。
- 删除记录时会尝试一并清理照片文件。

## 常见问题
- **没有看见统计图/报告**：可能是当前时间范围内没有数据，尝试调整至 “近 1 年” 或新增记录。
- **导出失败**：确保设备剩余存储空间充足，同时在“设置”中确认未关闭文件访问权限。
- **提醒无效果**：当前版本仅同步偏好，不含后台通知，详情参见 `TECHNICAL_NOTES.md`。
